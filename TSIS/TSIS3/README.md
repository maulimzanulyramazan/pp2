# 🏁 TSIS3 Racer Game - Advanced Racing Game

## 📋 Overview

TSIS3 Racer is an arcade-style racing game where players control a car on a scrolling highway, avoiding traffic and obstacles while collecting coins and power-ups. The game features dynamic difficulty scaling, a persistent leaderboard, and multiple game modes.

## ✨ Features

### Core Gameplay
- **Lane-based driving** - Choose between 4 lanes to avoid obstacles
- **Dynamic traffic** - Enemy cars with varying speeds and colors
- **Road hazards** - Barriers, oil spills, and potholes that affect gameplay
- **Weighted coins** - Bronze (1pt), Silver (2pt), and Gold (3pt) coins
- **Distance tracking** - Race to reach 3000 meters

### Power-Ups
| Power-Up | Effect | Duration |
|----------|--------|----------|
| 🟣 Nitro | Temporary speed boost | 3-5 seconds |
| 🔵 Shield | Protection from one collision | Until hit |
| 🟢 Repair | Removes one obstacle / instant bonus | Instant |

### Road Events
- **Moving Barrier** - Shifts between lanes
- **Speed Bump** - Temporary slowdown
- **Nitro Strip** - Instant speed boost

### Game Modes & Features
- **Main Menu** with Play, Leaderboard, Settings, Quit options
- **Username entry** - Save your high scores
- **Leaderboard** - Top 10 scores saved locally
- **Settings** - Sound toggle, Car color selection, Difficulty levels
- **Difficulty scaling** - Easy, Normal, Hard modes
- **Persistent storage** - Scores and settings saved as JSON

## 🎮 Controls

| Key | Action |
|-----|--------|
| ← (Left Arrow) | Move car left |
| → (Right Arrow) | Move car right |
| ESC | Pause / Return to menu |
| Enter | Confirm name input |

### Settings Menu Controls
| Key | Action |
|-----|--------|
| S | Toggle Sound ON/OFF |
| C | Change Car Color |
| D | Change Difficulty |
| V | Adjust Music Volume |
